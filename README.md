# 은평구 · 서울특별시

> 은평구 지역 정보 랜딩 사이트

## 🌐 랜딩 페이지

### **https://kr-seoul-eunpyeong.github.io/**

은평구는 서울특별시 북서부 끝자락에 위치한 자치구로, 북한산 능선과 불광천 물길을 함께 품은 대표적인 주거 지역이다. 옛 구파발이 의주로 향하던 관문이었던 만큼 예로부터 사람과 물자가 오가던 길목이었고, 오늘날에는 은평뉴타운과 진관동 한옥마을이 어우러진 독특한 경관을 이룬다. 연신내와 불광을 축으로 하는 촘촘한 생활 상권 덕분에 정주 여건이 좋아 가족 단위 거주지로 인기가 높다. 천년 고찰 진관사와 봉산 편백나무 숲처럼 도심에서 보기 드문 자연·문화 자원이 가까이 있어 사계절 나들이객의 발길이 이어진다.
